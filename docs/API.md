# API Documentation\n\n## Overview\n\nThe Nyansapo Teaching Dashboard includes a suite of REST API endpoints for handling assessments, data export, health checks, and communications.\n\n---\n\n## Base URL\n\n```\nhttps://yourdomain.com/api\n```\n\n---\n\n## Endpoints\n\n### 1. Health Check\n\n#### GET `/api/check`\n\nVerifies that the API server is running and responsive.\n\n**Purpose**: Health check and monitoring\n\n**Response**:\n```json\n{\n  \"status\": \"OK\",\n  \"timestamp\": \"2026-02-12T10:30:00Z\",\n  \"uptime\": 3600\n}\n```\n\n**Use Cases**:\n- Server monitoring\n- Uptime verification\n- Load balancer health checks\n\n---\n\n### 2. Contact Form\n\n#### POST `/api/contact`\n\nHandles contact form submissions and sends email notifications.\n\n**Purpose**: User inquiry collection and email notification\n\n**Request Body**:\n```json\n{\n  \"name\": \"John Doe\",\n  \"email\": \"john@example.com\",\n  \"subject\": \"Feature Request\",\n  \"message\": \"I would like to request a new feature...\",\n  \"phone\": \"+1234567890\" (optional)\n}\n```\n\n**Response**:\n```json\n{\n  \"success\": true,\n  \"message\": \"Your message has been sent successfully\",\n  \"ticketId\": \"TICKET-12345\"\n}\n```\n\n**Features**:\n- Email validation\n- Message sanitization\n- Ticket generation\n- Admin notification\n- Auto-reply to user\n\n**Integration**: Nodemailer for email delivery\n\n**Use Cases**:\n- Contact form on /contact-us page\n- User support requests\n- Feature suggestions\n\n---\n\n### 3. Literacy Assessment\n\n#### GET `/api/literacy`\n\nRetrrieves literacy assessment records and results.\n\n**Purpose**: Fetch literacy assessment data\n\n**Query Parameters**:\n```\n?organizationId=org123\n&schoolId=school456 (optional)\n&studentId=student789 (optional)\n&startDate=2026-01-01 (optional)\n&endDate=2026-02-12 (optional)\n```\n\n**Response**:\n```json\n{\n  \"success\": true,\n  \"assessments\": [\n    {\n      \"id\": \"literacy-001\",\n      \"studentId\": \"student789\",\n      \"studentName\": \"Jane Doe\",\n      \"score\": 85,\n      \"level\": \"Proficient\",\n      \"date\": \"2026-02-10\",\n      \"duration\": 3600,\n      \"audioUrl\": \"https://...\",\n      \"feedback\": \"Good fluency and comprehension\"\n    }\n  ],\n  \"total\": 150\n}\n```\n\n#### POST `/api/literacy`\n\nSubmits new literacy assessment results.\n\n**Purpose**: Record literacy assessment submissions\n\n**Request Body**:\n```json\n{\n  \"studentId\": \"student789\",\n  \"organizationId\": \"org123\",\n  \"score\": 85,\n  \"level\": \"Proficient\",\n  \"audioFile\": \"base64_encoded_audio\",\n  \"duration\": 3600,\n  \"metadata\": {\n    \"assessmentType\": \"reading_fluency\",\n    \"gradeLevel\": \"Grade 3\"\n  }\n}\n```\n\n**Response**:\n```json\n{\n  \"success\": true,\n  \"assessmentId\": \"literacy-001\",\n  \"message\": \"Assessment submitted successfully\"\n}\n```\n\n**Features**:\n- Audio file upload\n- Real-time scoring\n- AI-based feedback generation\n- Result persistence\n\n**Use Cases**:\n- Audio literacy assessments\n- Reading fluency evaluation\n- Phonics testing\n\n---\n\n### 4. Numeracy Assessment\n\n#### GET `/api/numeracy`\n\nRetrieves numeracy assessment records and results.\n\n**Purpose**: Fetch numeracy assessment data\n\n**Query Parameters**:\n```\n?organizationId=org123\n&schoolId=school456 (optional)\n&studentId=student789 (optional)\n&startDate=2026-01-01 (optional)\n&endDate=2026-02-12 (optional)\n```\n\n**Response**:\n```json\n{\n  \"success\": true,\n  \"assessments\": [\n    {\n      \"id\": \"numeracy-001\",\n      \"studentId\": \"student789\",\n      \"studentName\": \"Jane Doe\",\n      \"score\": 78,\n      \"level\": \"Developing\",\n      \"date\": \"2026-02-10\",\n      \"category\": \"number_recognition\",\n      \"questionsCorrect\": 15,\n      \"questionsTotal\": 20\n    }\n  ],\n  \"total\": 142\n}\n```\n\n#### POST `/api/numeracy`\n\nSubmits new numeracy assessment results.\n\n**Purpose**: Record numeracy assessment submissions\n\n**Request Body**:\n```json\n{\n  \"studentId\": \"student789\",\n  \"organizationId\": \"org123\",\n  \"score\": 78,\n  \"level\": \"Developing\",\n  \"category\": \"number_recognition\",\n  \"questionsAnswered\": [\n    {\"questionId\": \"q1\", \"answer\": \"5\", \"correct\": true},\n    {\"questionId\": \"q2\", \"answer\": \"3\", \"correct\": false}\n  ],\n  \"metadata\": {\n    \"assessmentType\": \"number_recognition\",\n    \"gradeLevel\": \"Grade 2\",\n    \"duration\": 1800\n  }\n}\n```\n\n**Response**:\n```json\n{\n  \"success\": true,\n  \"assessmentId\": \"numeracy-001\",\n  \"score\": 78,\n  \"message\": \"Assessment submitted successfully\"\n}\n```\n\n**Features**:\n- Multiple question types\n- Real-time scoring\n- Categorized results\n- Performance analytics\n\n**Use Cases**:\n- Math skills assessment\n- Number recognition\n- Arithmetic evaluation\n\n---\n\n### 5. Data Export\n\n#### POST `/api/export`\n\nGenerates and exports data in various formats.\n\n**Purpose**: Export assessment and operational data\n\n**Request Body**:\n```json\n{\n  \"organizationId\": \"org123\",\n  \"exportType\": \"assessments\",\n  \"format\": \"xlsx\",\n  \"filters\": {\n    \"startDate\": \"2026-01-01\",\n    \"endDate\": \"2026-02-12\",\n    \"assessmentTypes\": [\"literacy\", \"numeracy\"],\n    \"grades\": [\"Grade 1\", \"Grade 2\"]\n  },\n  \"columns\": [\n    \"studentName\",\n    \"grade\",\n    \"assessmentType\",\n    \"score\",\n    \"level\",\n    \"date\"\n  ]\n}\n```\n\n**Response**:\n```\nBinary file (Excel, CSV, or PDF)\n\nHeaders:\nContent-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet\nContent-Disposition: attachment; filename=export_2026_02_12.xlsx\n```\n\n**Supported Export Types**:\n- `assessments` - Assessment results\n- `attendance` - Attendance records\n- `students` - Student information\n- `instructors` - Instructor data\n- `report` - Comprehensive report\n\n**Supported Formats**:\n- `xlsx` - Excel format\n- `csv` - CSV format\n- `pdf` - PDF format\n\n**Features**:\n- Flexible column selection\n- Date range filtering\n- Assessment type filtering\n- Grade level filtering\n- Batch processing for large datasets\n\n**Use Cases**:\n- Data analysis\n- Report generation\n- Data backup\n- Compliance reporting\n\n---\n\n## Authentication\n\nAll API endpoints (except `/api/check` and `/api/contact`) require authentication:\n\n**Method**: Firebase Auth Token\n\n**Header**:\n```\nAuthorization: Bearer <firebase_id_token>\n```\n\n**How to get token**:\n```javascript\nconst user = await firebase.auth().currentUser;\nconst token = await user.getIdToken();\n```\n\n---\n\n## Error Handling\n\nAll endpoints follow standard error response format:\n\n**Error Response**:\n```json\n{\n  \"success\": false,\n  \"error\": \"Error description\",\n  \"code\": \"ERROR_CODE\",\n  \"details\": {}\n}\n```\n\n**Common Error Codes**:\n- `401_UNAUTHORIZED` - Missing or invalid auth token\n- `403_FORBIDDEN` - User lacks permission\n- `404_NOT_FOUND` - Resource not found\n- `400_BAD_REQUEST` - Invalid request body\n- `500_INTERNAL_ERROR` - Server error\n\n---\n\n## Rate Limiting\n\n- **Default**: 1000 requests per hour per user\n- **Burst**: 100 requests per minute\n- **Response Header**: `X-RateLimit-Remaining`\n\n---\n\n## Request/Response Examples\n\n### Example: Submit Literacy Assessment\n\n**Request**:\n```bash\ncurl -X POST https://yourdomain.com/api/literacy \\\n  -H \"Authorization: Bearer <token>\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"studentId\": \"student123\",\n    \"organizationId\": \"org456\",\n    \"score\": 85,\n    \"level\": \"Proficient\",\n    \"duration\": 3600\n  }'\n```\n\n**Response**:\n```json\n{\n  \"success\": true,\n  \"assessmentId\": \"literacy-12345\",\n  \"message\": \"Assessment submitted successfully\"\n}\n```\n\n---\n\n### Example: Export Assessment Data\n\n**Request**:\n```bash\ncurl -X POST https://yourdomain.com/api/export \\\n  -H \"Authorization: Bearer <token>\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"organizationId\": \"org456\",\n    \"exportType\": \"assessments\",\n    \"format\": \"xlsx\"\n  }' \\\n  --output assessments.xlsx\n```\n\n---\n\n## Webhooks\n\nOptional webhook support for real-time notifications:\n\n**Events**:\n- `assessment.submitted` - New assessment submitted\n- `assessment.graded` - Assessment graded\n- `attendance.marked` - Attendance marked\n\n**Setup**:\nConfigure webhook URLs in organization settings.\n\n---\n\n## Best Practices\n\n1. **Always include organization ID** for multi-tenant operations\n2. **Use date ranges** for large data queries\n3. **Implement error handling** for all API calls\n4. **Cache responses** when appropriate\n5. **Monitor rate limits** and adjust request frequency\n6. **Validate input** before sending requests\n7. **Use appropriate HTTP methods** (GET, POST, etc.)\n8. **Handle authentication** securely\n\n---\n\n**API Version**: 1.0\n**Last Updated**: February 2026"
