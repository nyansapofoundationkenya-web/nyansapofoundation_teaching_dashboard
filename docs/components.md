# Component Documentation

## AI Assistant
- **ChatHeader.jsx**: This component renders the header for the chat interface.
- **ChatInput.jsx**: This component allows users to input their messages.
- **ChatMessage.jsx**: This component displays individual messages in the chat.
- **ConversationHistory.jsx**: This component shows the history of the conversation.
- **DashboardChatBot.jsx**: This is the main chat bot component that handles user interactions.
- **LoadingIndicator.jsx**: This component shows a loading spinner when the chat is processing.
- **toolExecutor.js**: This file contains functions to execute tools based on user input.

## Assessments
- **AddStudentModal.jsx**: This modal allows users to add new students to the system.
- **GradeFilter.jsx**: This component provides filtering options for grades.
- **Search.jsx**: This component allows users to search for assessments.
- **StudentMetrics.jsx**: This component displays metrics related to students.
- **StudentsList.jsx**: This component lists all students in the system.

## Attendance
- **Attendance-dashboard.jsx**: This component serves as the main dashboard for attendance tracking.
- **AttendanceTable.jsx**: This component displays attendance records in a tabular format.

## Audio Moderation
- **AssessmentResults.jsx**: This component displays the results of audio assessments.
- **AudioModerationContent.jsx**: This component contains the content for audio moderation.
- **AudioPlayer.jsx**: This component allows users to play audio files.
- **LiteracyNavigationControls.jsx**: This component provides navigation controls for literacy assessments.
- **ModerationActions.jsx**: This component contains actions for moderating audio content.
- **StudentHeader.jsx**: This component displays the header for student audio moderation.

## Auth
- **LoginForm.jsx**: This component handles user login functionality.
- **SignupForm.jsx**: This component handles user signup functionality.

## Button
- **AddOrganizationButton.jsx**: This button allows users to add a new organization.
- **Button.jsx**: This is a generic button component used throughout the application.
- **DemoOrganizationButton.jsx**: This button is used for demo purposes.
- **GoBackButton.jsx**: This button allows users to navigate back to the previous page.
- **OrganizationButton.jsx**: This button is used for organization-related actions.

## Charts
- **GradeLevelChart.jsx**: This component displays the distribution of grades across levels.
- **LevelDistributionByAge.jsx**: This component shows the distribution of levels by age.
- **LevelDistributionByGenderChart.jsx**: This component displays the distribution of levels by gender.
- **ProjectCharts.jsx**: This component contains various charts related to projects.

## Dashboard
- **Header.jsx**: This component renders the header for the dashboard.
- **SideBar.jsx**: This component provides navigation options in the sidebar.
- **UserProfileModal.jsx**: This modal displays user profile information.

## Welcome
- **Welcome.jsx**: This component serves as the welcome page for the application.
