# Hooks Documentation

## Custom Hooks
- **useAnalysis.js**: This hook provides functionality for analyzing data.
- **useAssessment.js**: This hook manages assessment-related logic.
- **useAuth.js**: This hook handles authentication processes.
- **useHouseholdDetails.js**: This hook retrieves and manages household details.
- **useInstructorActions.js**: This hook provides actions related to instructors.
- **useInstructors.js**: This hook manages instructor data.
- **useIsLoggedIn.js**: This hook checks if a user is logged in.
- **useMultipleSheetUpload.js**: This hook facilitates the upload of multiple sheets.
- **useOrganization.js**: This hook manages organization-related data.
- **useProjectDetails.js**: This hook retrieves project details.
- **useSchools.js**: This hook manages school-related data.
- **useSchoolStudents.js**: This hook manages students within schools.
